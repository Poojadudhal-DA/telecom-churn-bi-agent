# 📊 Telecom Customer Churn BI Agent

## 🔍 Project Overview
An end-to-end Business Intelligence project that 
analyzes telecom customer churn using Python, 
Power BI, and a Rule-Based AI Agent.

## 🛠️ Tools Used
- **Python** — Data cleaning and EDA
- **Pandas** — Data manipulation
- **Streamlit** — Web application
- **Power BI** — Business dashboard
- **Jupyter Notebook** — Data analysis
- **GitHub** — Version control

## 📁 Project Structure
## 📊 Dataset
- Source: Telco Customer Churn Dataset
- Rows: 7,043 customers
- Columns: 21 features

## 🔑 Key Insights
- 🔴 Churn Rate: **26.54%**
- 🔴 Month-to-month contracts = highest churn
- 🔴 Fiber optic users = 69.4% of churned customers
- 🔴 Electronic check = most common payment in churned
- 🔴 New customers (1-5 months) = highest churn risk

## 📌 KPI Summary

## 🤖 AI Agent Features
Ask the BI Agent questions like:
- "What is the churn rate?"
- "Which contract type churns most?"
- "Tell me about payment methods"
- "What about tenure?"
